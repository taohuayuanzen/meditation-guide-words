# 音频停顿编排人工验收清单

> 使用 Mock/FakeTTS；本清单不得触发真实付费 TTS。

## 准备

- 准备一个 `pause_capable=true` 的结构化引导词和一个旧版引导词。
- 确认 FFmpeg/FFprobe 正常；另准备一次不可用环境验证阻断提示。
- 分别切换中文和英文完成一轮检查。

## 工作区

- [ ] 三档依次为 `gentle_v1`、`standard_v1`、`deep_v1`，默认标准，文案随语言变化但 ID 不变。
- [ ] 旧版引导词有明确标记且预览按钮禁用；历史任务仍可播放。
- [ ] 生成预览不创建 AudioTask，也不调用 TTS。
- [ ] 摘要包含总时长、目标、语音、自然停顿、冥想留白、留白数量、最长留白、模型、音色和档案。
- [ ] 时长小于一分钟显示秒，其余显示 `X分Y秒` / `Xm Ys`。
- [ ] 超过目标 ±10% 显示警告但仍允许确认。
- [ ] 修改脚本、档案、声音描述、TTS provider/model/voice 或脚本更新时间后不能提交旧 preview。
- [ ] 双击确认只创建一个任务；成功后清除 preview，保留三项输入。
- [ ] preview 校验失败、过期、模型音色不匹配、段数过多均保留输入并显示安全错误。
- [ ] FFmpeg/FFprobe 不可用时禁用确认并显示运维引导。

## 任务卡

- [ ] 阶段按排队、分段合成、拼接、编码、校验、完成/失败展示。
- [ ] 合成阶段显示 `已完成 N / M 段`。
- [ ] provider、model、voice、pause profile 使用任务快照，不受当前设置影响。
- [ ] 展示预计总时长；完成后展示实测时长及相对预计偏差。
- [ ] 失败重试说明复用 render plan 和 TTS 快照；本地后处理失败说明不重做已完成语音段。
- [ ] 错误不含 API Key、服务器绝对路径或完整引导词。
