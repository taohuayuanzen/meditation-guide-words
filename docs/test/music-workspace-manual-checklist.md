# 纯音乐工作区人工验收清单

## 前置检查

- [ ] `ffmpeg -version`、`ffprobe -version` 成功，能力 API 三项均为 `true`。
- [ ] 后端全量测试和 Ruff、前端 lint/build 通过，自动测试未调用真实模型。
- [ ] 真实联调前已单独确认 MiniMax Key、最大模型调用次数及产物保留规则。

## 双供应商设置

- [ ] 音乐设置默认选择 MiniMax，模型只读 `music-3.0`，源格式只读 MP3。
- [ ] MiniMax 显示 API Key、Base URL、纯音乐开启、水印关闭，不显示 Workspace ID 或复制阿里云 TTS Key。
- [ ] 阿里云保留 Workspace ID、API Key、Base URL、`fun-music-v1`、源 WAV 与复制 TTS Key。
- [ ] MiniMax 和阿里云来回切换、保存并刷新后，两套凭证各自保留且不互相覆盖。
- [ ] 配置检查只验证当前供应商配置和 FFmpeg/FFprobe，不调用真实模型。
- [ ] MiniMax 缺少 Key 时禁用新任务；阿里云缺少 Key 或 Workspace ID 时禁用新任务；已有任务仍可查看和下载。

## 工作区与任务快照

- [ ] Prompt 首句为“创作适合纯音乐。”，长度限制 1～2000 字符。
- [ ] 新 MiniMax 任务显示 MiniMax / `music-3.0` / MP3；旧任务显示阿里云 / `fun-music-v1` / WAV。
- [ ] 切换全局供应商不改变任何已有任务的供应商、模型或源格式。
- [ ] MiniMax 任务显示真实源时长和“费用以 MiniMax 账单为准”，不显示 `¥0.00`。
- [ ] 阿里云任务继续显示源时长、估算费用及“以阿里云账单为准”。
- [ ] active 任务每 3 秒刷新，正确显示生成、下载、源就绪、时长处理阶段。

## 重试、文件与产物

- [ ] MiniMax 任意生成失败后立即停止，Worker 不自动再次调用模型。
- [ ] MiniMax 手动重新生成前显示可能重复计费确认；取消后不发请求。
- [ ] 下载或 FFmpeg 失败且已有 URL/源文件时，重试不显示模型计费确认且不调用模型。
- [ ] URL 过期且本地源文件不存在时明确失败，不自动生成。
- [ ] MiniMax 原始 MP3 与目标时长 MP3 均可下载，MIME、扩展名、大小、时长正确。
- [ ] 阿里云原始 WAV 与最终 MP3 的试听、下载和恢复行为保持不变。
- [ ] 产物页显示供应商、模型、目标时长、时间与 AI 标识，并可播放、下载、重命名和删除。
- [ ] 重命名只修改最终 MP3；删除提示使用“原始音乐”，并清理源 WAV/MP3、临时文件、最终 MP3 和任务记录。
- [ ] 中英文文案完整，没有把所有源文件写死为 WAV。

## 真实 MiniMax 联调（需用户单独授权）

- [ ] 使用默认预设创建一条目标 5 分钟任务，调用次数不超过已授权上限。
- [ ] 请求为非流式、URL、MP3、`is_instrumental=true`，不发送歌词。
- [ ] 成功 URL 先持久化，再下载并长期保留原始 MP3。
- [ ] 最终 MP3 与 300 秒误差不超过 1 秒，播放器与两个 MP3 下载正常。
- [ ] 用户试听确认没有可辨识人声、吟唱、歌词或念白；不通过时不自动再次生成。
