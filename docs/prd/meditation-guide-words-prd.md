# 冥想音频工作台 PRD

## 1. 项目概述

### 1.1 产品定位
一款面向个人的网页端冥想音频工作台，通过自然语言对话生成冥想引导文本，并基于文本与声音提示词生成专业级冥想音频。工具采用 Dify 开源版作为智能体编排框架，支持 LLM 与 TTS 模型在设置页灵活配置。

### 1.2 目标用户
- 冥想创作者、瑜伽教练、心理咨询师
- 需要自制冥想音频的个人用户
- 对 AI 内容生成与语音合成感兴趣的探索者

### 1.3 核心价值
- 零门槛生成高质量冥想引导词
- 自然语言驱动音频音色、语速、情绪控制
- 本地运行，数据不出本机
- 双工作区并行，随时引用文本生成音频

---

## 2. 技术栈

| 层级 | 选型 | 说明 |
|---|---|---|
| 智能体框架 | Dify 开源版 | 低代码编排 Chat/Agent/Workflow，内置 Prompt 管理、多模型接入 |
| 前端 | React + TypeScript | 现代 UI 框架，强类型支持 |
| 后端 | Python FastAPI | 提供设置、文件下载、任务状态等轻量 API |
| LLM | DeepSeek / Kimi（可配置） | 通过设置页配置 API Key、Base URL、模型名 |
| TTS | 火山引擎 / 阿里云（可配置） | 通过设置页配置 API Key、模型/音色、语速等 |
| 数据存储 | SQLite | 本地轻量存储会话、引导词、音频任务元数据 |
| 音频存储 | 本地文件系统 | 生成音频存放于本地目录 |
| 部署目标 | 本地运行 | 单用户桌面/浏览器访问 |

## 4. 功能需求

### 4.1 左侧边栏工作区切换
- 常驻左侧边栏，显示两个工作区入口
- 当前工作区高亮
- 切换时保留各工作区会话状态（草稿、历史记录）

### 4.2 工作区 1：引导词生成

#### 4.2.1 对话生成
- 用户以自然语言描述需求，例如：
  - "生成一段 10 分钟睡前放松冥想引导词"
  - "把刚才的引导词改成 5 分钟版本"
  - "加入更多身体扫描元素"
- LLM 流式返回引导词文本（打字机效果）
- 支持多轮对话改写、扩写、缩写、换风格

#### 4.2.2 引导词管理
- 可标记某轮输出为"正式版"并保存到本地
- 每条引导词包含：标题、内容、创建时间、关联会话 ID
- 支持复制、删除、重新生成
- 工作区 2 可直接引用已保存的引导词

### 4.3 工作区 2：音频生成

#### 4.3.1 引用引导词
- 下拉选择或卡片选择工作区 1 中已保存的引导词
- 显示引用文本预览，支持在该工作区中局部微调

#### 4.3.2 声音提示词对话
- 用户用自然语言描述声音需求，例如：
  - "温柔成熟的女声，语速慢，正念风格"
  - "低沉男声，带安抚感，音量平稳"
- Agent 解析后生成结构化的 TTS 参数：音色 ID、语速、音量、情绪标签等

#### 4.3.3 异步生成
- 提交生成任务后进入队列
- 显示任务状态：排队中 / 合成中 / 已完成 / 失败
- 完成后支持在线播放、下载 MP3/WAV
- 任务失败后显示错误信息并允许重试

### 4.4 设置页

#### 4.4.1 大模型配置（LLM）
- 模型供应商选择：DeepSeek / Kimi / 自定义 OpenAI-Compatible
- 配置项：
  - API Base URL
  - API Key
  - 模型名称
  - 温度（Temperature，默认 0.7）
  - 最大 token（可选）
- 支持"测试连接"按钮

#### 4.4.2 TTS 模型配置
- TTS 供应商选择：火山引擎 / 阿里云 / 自定义
- 配置项：
  - API Key / Access Key
  - Secret Key（如需要）
  - 默认音色 ID
  - 默认语速
  - 默认音量
  - 输出格式（MP3 / WAV，默认 MP3）
- 支持"测试合成"按钮

#### 4.4.3 通用设置
- 默认语言：中文 / 英文
- 音频保存目录
- 主题：浅色 / 深色

## 6. Dify 工作流设计

### 6.1 工作区 1：引导词生成 Chatflow
```
用户输入 → 变量聚合（历史对话 + 当前输入） → LLM（DeepSeek/Kimi） → 输出引导词
```
- System Prompt：定义角色为"冥想引导词创作专家"，要求输出结构清晰、节奏舒缓、适合朗读的引导词
- 流式输出开启
- 多轮对话上下文保留

### 6.2 工作区 2：音频生成 Chatflow
```
用户输入（声音描述）
    ↓
引用脚本内容（从外部传入变量）
    ↓
LLM 解析提示词 → 输出 TTS 参数 JSON
    ↓
调用 TTS 工具节点（火山/阿里，或 FastAPI 代理）
    ↓
返回音频 URL / 任务 ID
```
- System Prompt：要求 LLM 从自然语言中提取音色、语速、音量、情绪，输出为固定 JSON Schema
- TTS 节点由 FastAPI 后端代理实现，便于统一凭证管理和异步队列

## 7. 接口设计（FastAPI 后端）

### 7.1 设置接口
- `GET /api/settings`：获取 LLM、TTS、通用设置
- `POST /api/settings`：保存设置
- `POST /api/settings/test-llm`：测试 LLM 连接
- `POST /api/settings/test-tts`：测试 TTS 连接

### 7.2 引导词接口
- `GET /api/scripts`：列出所有引导词
- `POST /api/scripts`：保存引导词
- `GET /api/scripts/{id}`：获取单条引导词
- `PUT /api/scripts/{id}`：更新引导词
- `DELETE /api/scripts/{id}`：删除引导词

### 7.3 音频任务接口
- `POST /api/audio-tasks`：提交音频生成任务
- `GET /api/audio-tasks`：列出任务列表
- `GET /api/audio-tasks/{id}`：获取任务状态
- `GET /api/audio-tasks/{id}/download`：下载音频文件
- `POST /api/audio-tasks/{id}/retry`：重试失败任务

## 9. 非功能需求

### 9.1 性能
- LLM 流式首字响应时间 ≤ 3 秒（取决于模型与网络）
- TTS 异步任务支持队列并发控制，默认同时处理 2 个任务

### 9.2 可靠性
- 任务状态持久化到 SQLite，程序重启不丢失
- TTS 失败自动重试 1 次，仍失败则标记失败并记录错误

### 9.3 安全
- API Key 仅存储在本地 SQLite，不对外传输
- 本地运行，不开放公网访问

### 9.4 兼容性
- 支持 Chrome / Edge / Safari / Firefox 现代浏览器
- 支持中文、英文界面切换
